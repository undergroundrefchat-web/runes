# Руны

PWA: вытянуть руны Старшего Футарка или карты таро Уэйта — одну, три или сколько нужно. Без сборки и зависимостей:
обычные файлы, открываются любым статическим сервером. Работает без интернета, ставится на экран телефона.

## Запустить локально

```sh
python3 -m http.server 8000 -d ~/Desktop/my-folder/rune-bag
# открыть http://localhost:8000
```

Чтобы поставить на телефон, нужен адрес с https (Netlify, GitHub Pages, свой сервер).

## Где что лежит

| Файл | Что внутри |
|---|---|
| `js/decks.js` | колоды и их расклады; какая колода выбрана |
| `js/data/runes.js` | 24 руны + пустая: название, рисовка (`path`), смысл названия, толкования |
| `js/data/waite.js` | 78 карт Уэйта–Смит: названия, масти |
| `img/waite/` | картинки карт 480×832 webp (издание 1909, общественное достояние) |
| `tools/waite_images.py` | пересобрать картинки из сканов Wikimedia Commons |
| `js/pages/` | разделы бокового меню (История, Все руны / Все карты, Настройки) |
| `js/app.js` | главный экран: расклад и кнопки |
| `js/core.js` | хранилище, случай, отрисовка диска и карты, настройки по умолчанию |
| `js/ui.js` | лист снизу, меню, страницы, тост |
| `css/app.css` | весь вид; цвета — переменные в начале файла |
| `sw.js` | офлайн-кэш |

## Как дополнять

- **Новый расклад** — строка в `spreads` нужной колоды в `js/decks.js`, например
  `{ id: 'five', name: 'Пять рун', count: 5 }`. Он сам появится в «Расклады» и в меню.
- **Новая колода** — данные в `js/data/`, объект в `DECKS` в `js/decks.js` (поля описаны там же),
  картинки в `img/<колода>/` и их список в `sw.js`.
- **Новый раздел меню** — файл в `js/pages/` вида `export default { id, title, render(el) { … } }`
  и строка в `js/pages/index.js`.
- **Новая настройка** — строка в `OPTIONS` в `js/pages/settings.js` и значение по умолчанию в `settings` в `js/core.js`.
- **Цвета** — переменные `:root` в начале `css/app.css` (`--disc`, `--rune`, `--bar`, `--fab-main` …).
- **Добавил новый файл** — впиши его в `FILES` в `sw.js` и подними номер `CACHE`, иначе офлайн-версия его не увидит.

Данные пользователя — только в `localStorage` этого устройства:
`runes.settings`, `app.deck` (выбранная колода), `runes.current` и `waite.current` (стол каждой колоды),
`runes.history` (история всех колод).
